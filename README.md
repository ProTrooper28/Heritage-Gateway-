# Heritage Gateway

Create a premium desktop login/onboarding experience for "Indian Heritage AI".

The experience should consist of 5 full-screen slideshow pages followed by a login screen.

Each slide represents one iconic Indian monument.

Slides:

1. Brihadeeswara Temple

Theme:

Power & Legacy

2. Taj Mahal

Theme:

Love & Architecture

3. Hampi

Theme:

Ruins of Grandeur

4. Qutub Minar

Theme:

Victory & History

5. Konark Sun Temple

Theme:

Symbolism in Stone

Each slide should include:

• One huge monument

• Massive editorial typography

• One emotional subtitle

• One or two floating premium information cards

• Very minimal UI

• Large whitespace

• Dark luxury aesthetic

• Premium serif typography

• Glassmorphism cards

• Soft golden lighting

No dashboards.

No feature grids.

No mobile UI.

No buttons except a small "Skip" option.

Design every slide so it can be animated with:

- Slow zoom

- Parallax

- Fade transitions

- Floating cards

- Typography reveal

- Light rays

- Dust particles

After the slideshow, create the final login page.

The login page should keep the same visual language.

Background:

A subtle blend of all monuments with a dark overlay.

Center glassmorphism card containing:

Indian Heritage AI

Experience history like never before.

Buttons:

• Continue as Guest

• Sign in with Google

• Explore Heritage

Minimal footer.

Award-winning editorial design.

Apple + Awwwards + Google Arts & Culture quality.

Output high-fidelity desktop UI mockups only.
